FluentSystemIcons-Regular.ttf is a subset of the "Fluent UI System Icons" font by Microsoft
(https://github.com/microsoft/fluentui-system-icons, fonts/FluentSystemIcons-Regular.ttf), reduced with
fontTools' pyftsubset to the glyphs listed in src/OgConverter.Linux/Icons/Icons.cs. It is distributed under
the MIT License below.

To add an icon: take the full font and its FluentSystemIcons-Regular.json from that repository, add the
code point to Icons.cs, and run
    pyftsubset FluentSystemIcons-Regular.ttf --unicodes=<every code point in Icons.cs> \
        --layout-features='' --no-hinting --name-IDs='*' --output-file=FluentSystemIcons-Regular.ttf
